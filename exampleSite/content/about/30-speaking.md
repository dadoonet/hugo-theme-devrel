Alex (still fictional) talks about search, observability, and community. Recurring abstracts live under `/talks/templates/`. The map at `/talks/map/` is built from `conference.latitude` and `conference.longitude` on each talk — there is no separate geo database.

If you present in more than one language, set `talk-lang` on the talk and add a `versions` entry on the template. The theme renders tabs so you can paste the right abstract into a CFP.
