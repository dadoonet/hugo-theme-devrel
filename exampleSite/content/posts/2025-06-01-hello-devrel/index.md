This is a **fictional** sample post shipped with `hugo-theme-devrel`. Copy the folder layout, not the biography: Alex Rivera does not exist.

<!--more-->

Use page bundles under `content/posts/YYYY-MM-DD-slug/` with an `index.md` file and optional assets (`cover.svg`, diagrams, screenshots) next to it.

```text
content/posts/2025-06-01-hello-devrel/
├── index.md
└── cover.svg
```

Front matter follows the same conventions as a real DevRel blog: `tags`, `categories`, optional `series`, and a `cover` image for cards and search results.

The live production site that inspired this theme is [david.pilato.fr](https://david.pilato.fr/). This example site stays small on purpose so you can delete the fiction and start writing.
